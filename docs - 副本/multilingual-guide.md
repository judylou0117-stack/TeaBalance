# 五语言界面说明

Tea Balance 第一阶段支持简体中文（zh）、English（en）、日本語（ja）、한국어（ko）和 हिन्दी（hi）。页面固定文案全部位于 `data/translations/`，27 道标准题位于 `data/question-translations.json`，对话频率词和模拟追问位于 `data/conversation-simulation.json`。

语言选择保存在浏览器的 `sessionStorage`。切换语言只改变显示和后续模块请求的目标语言，不会清空安全信息、已记录答案、题号或用户原话。

模块 A 接收稳定语言代码，只能返回 1—5 级候选、澄清或冲突。模块 B 的输入新增 `outputLanguage`；提示词要求解释使用所选语言，同时不得改变转化分、体质编码、茶饮编号、知识编号和安全提醒。

翻译加载按“所选语言 → 英文 → 中文”回退。自动测试会比较五份翻译文件的 key，并检查三种新增语言的题目、频率、模块请求与状态保留。

注意：界面、题目和 AI 输出语言已扩展，不代表规则 JSON 与知识库正文已经完整翻译。当前规则编码、tea_id、knowledge_id 和中文结构化知识继续共用；日语、韩语、印地语中的医学或标准术语建议在正式发布前由熟悉相应语言与健康传播边界的人员人工复核。
